# Apna Salon 💇‍♂️

A responsive salon website built using HTML, CSS and JavaScript.

## 📌 About The Project

Apna Salon is a modern and responsive salon website designed to give customers information about the salon, available services, gallery, contact details and appointment booking.

## ✨ Features

* Responsive design for desktop and mobile
* Navigation between different sections
* Appointment booking form
* Service cards with prices
* Salon gallery
* Contact information
* Instagram profile button
* Back-to-top button
* Mobile-friendly navigation menu

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 📂 Website Sections

* **Home** — Introduction and appointment booking
* **About** — Information about Apna Salon
* **Services** — Available salon services and prices
* **Gallery** — Salon images
* **Contact** — Phone, email and location details

## 📝 Appointment Form

The appointment form collects:

* Customer name
* Phone number
* Selected service

The form also checks the entered information before showing an appointment confirmation message.

## 📱 Responsive Design

The website is designed to work on both desktop and smaller screen sizes.

## 🚀 Future Improvements

* Connect appointments to a real database
* Add WhatsApp booking
* Add real salon location/map
* Add an online payment option
* Add real customer reviews
* Connect the website with the salon's actual social media accounts

## 👨‍💻 Project Purpose

This project was created as a practical web development project to learn how to build and prepare a real-world business website.
