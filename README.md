# Apna Salon 💇‍♂️

A responsive salon business website built using HTML, CSS and JavaScript.

## 📌 About The Project

Apna Salon is a modern and responsive salon website designed to provide customers with information about the salon, available services, gallery, contact details and appointment booking.

## ✨ Features

- Responsive design for desktop and mobile
- Mobile-friendly navigation menu
- Navigation between different sections
- Appointment booking form
- Service cards with prices
- Salon gallery
- Contact information
- Instagram profile button
- Back-to-top button

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 📂 Website Sections

- **Home** — Introduction and appointment booking
- **About** — Information about Apna Salon
- **Services** — Available salon services and prices
- **Gallery** — Salon images
- **Contact** — Phone, email and location details

## 📝 Appointment Form

The appointment form collects:

- Customer name
- Phone number
- Selected service

The form checks the entered information before showing an appointment confirmation message.

## 📱 Responsive Design

The website is designed to work on desktop and smaller screen sizes.
